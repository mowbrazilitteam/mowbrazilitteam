# Tecnologia da Informação · MOW Brazil

Time de TI da **MOW Brazil** — beneficiamento e exportação de madeira, com sede
em Foz do Iguaçu, armazém em Santa Catarina e operação comercial na Europa,
América do Norte, América Latina e Ásia.

Cuidamos de infraestrutura, sistemas internos, suporte e segurança da informação.

## Como trabalhamos

- Toda mudança nasce numa branch própria, com um teste que reproduz o problema,
  e só entra em produção depois de revisão independente e aprovação.
- Automatizamos o trabalho repetitivo da operação: integrações com planilhas,
  ERP e comunicação com as equipes.
- Os dados da empresa ficam dentro de casa: os modelos de IA rodam em
  infraestrutura própria.

## Tecnologias

- **Linguagem:** Python, Java Script, C.
- **Aplicações web e APIs:** FastAPI, Django, Flask
- **Banco de dados:** PostgreSQL
- **Aplicativos móveis:** Flutter
- **Interfaces internas:** HTMX, Tailwind CSS
- **Inteligência artificial:** modelos locais com Ollama, transcrição com Whisper
- **Infraestrutura:** Linux, Docker
- **Qualidade e segurança:** pytest, Ruff, mypy, Bandit, pip-audit, gitleaks, Dependabot

Os sistemas que construímos são internos, e os repositórios desta conta são
privados.
